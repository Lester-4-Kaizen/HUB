Types of Data Analytics

📎Module 01 — Introduction to Advanced Data Analytics · Giralyn R. Ongco, PhDTM
There are four types of data analytics — each answering a progressively deeper question: Descriptive (what happened?), Diagnostic (why did it happen?), Predictive (what will happen?), and Prescriptive (what should we do?). Together they form a spectrum from simple reporting to fully automated, AI-driven decision support.
1️⃣

Descriptive Analytics — What Happened?

01
Descriptive Analytics
Definition: A type of data analytics that summarizes historical data to understand what has already happened.
What it Does:
  • Collects and organizes historical data into meaningful formats
  • Presents results using tables, charts, graphs, and dashboards
  • Shows trends, totals, averages, and percentages
Common Techniques: Counts and totals · Averages and percentages · Frequency distributions · Time-series summaries · Basic data visualization (bar charts, line graphs, pie charts)
2️⃣

Diagnostic Analytics — Why Did It Happen?

02
Diagnostic Analytics
Definition: A type of data analytics that focuses on examining data to understand why something happened.
What it Does:
  • Investigates relationships between variables
  • Identifies patterns, correlations, and anomalies
  • Breaks data down into smaller parts (drill-down)
  • Performs root cause analysis
Common Techniques: Data comparison (before vs. after) · Correlation analysis · Trend analysis · Drill-down and slice-and-dice · Root cause tools: Fishbone (Ishikawa) diagram, Pareto analysis, Variance analysis
3️⃣

Predictive Analytics — What Will Happen?

03
Predictive Analytics
Definition: A type of data analytics that uses historical data, statistical techniques, and machine learning models to predict future outcomes.
How it Works: Looks for patterns in past data → builds predictive models → forecasts future events.
  1. Collect historical data
  2. Identify patterns and trends
  3. Build predictive models
  4. Test and validate results
  5. Use the model to make predictions
Common Techniques: Regression analysis · Time-series forecasting · Classification models · Machine learning algorithms · Statistical modeling
4️⃣

Prescriptive Analytics — What Should We Do?

04
Prescriptive Analytics
Definition: A type of data analytics that recommends actions to take in order to achieve the best possible outcome, based on data, predictions, and constraints.
How it Works: Combines Descriptive + Diagnostic + Predictive, then:
  1. Evaluates possible decisions
  2. Considers constraints (time, cost, resources, policies)
  3. Recommends the optimal action
Common Techniques: Optimization models · Decision trees · Simulation · Rules engines · AI-driven recommendation systems
📈 The Analytics Spectrum — From Simple to Complex Progression ›
The four types form a progression: Descriptive → Diagnostic → Predictive → Prescriptive. Each level adds more complexity and more value. Descriptive is the simplest (what happened). Prescriptive is the most sophisticated (what to do). Most organizations start with descriptive analytics and evolve toward prescriptive as they mature their data capabilities.
💡 Think of it as a ladder: you must build up from descriptive before you can prescribe optimal actions. Each rung depends on the one below it.
🔧 Root Cause Analysis Tools in Diagnostic Analytics Techniques ›
Fishbone (Ishikawa) Diagram: Visualizes the causes of a specific problem — structured as a fish skeleton where each bone represents a category of cause (people, process, equipment, etc.). Pareto Analysis: Based on the 80/20 rule — identifies the 20% of causes responsible for 80% of problems. Variance Analysis: Compares actual vs. expected outcomes to identify deviations and understand why they occurred.
💡 These tools are used in quality management, healthcare, manufacturing, and business process improvement.
🤖 Machine Learning in Predictive Analytics ML Techniques ›
Regression Analysis: Predicts a continuous value (e.g., predicting next month's sales). Classification Models: Predicts a category (e.g., will this customer churn — yes/no?). Time-Series Forecasting: Predicts values over time using historical sequential data (e.g., stock prices, weather). ML algorithms like Random Forest, Neural Networks, and Support Vector Machines are common in advanced predictive models.
💡 Predictive analytics is the foundation for most business intelligence tools today — from CRM churn prediction to supply chain forecasting.
⚙️ Optimization Models in Prescriptive Analytics Optimization ›
Optimization Models are mathematical models used to determine the best possible decision under a given set of constraints, objectives, and business rules. Examples: airline route optimization, hospital staffing schedules, supply chain routing. Simulation models "what-if" scenarios — testing many possible futures before committing to an action. Decision Trees model branching decisions and their consequences, helping select the option with the best expected outcome.
💡 Prescriptive analytics is the highest level — it doesn't just tell you what will happen but tells you what to do about it.
